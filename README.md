Entry for make.fun's **Real-Life Patch Notes: The Comedy Changelog** bounty
([competition page](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d)).

`main.py` writes exactly one patch note — a software changelog entry for a bug
in human biology — to `/output/entry.txt`:

> v4.1.0: fixed a bug where the brain replayed your most embarrassing moment from 2009 every night at 3 a.m.

A real release-note register, a true grievance, and the turn lands in the
last few words: the patch ships, but the 3 a.m. replay was the feature all along.

## Run it

```sh
python3 main.py
```
